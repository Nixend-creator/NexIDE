# NIXEND Error Handling and Safety Skill

1. Для `catch (Throwable)` або `catch (Exception)` викликай `rethrowControlFlowException(e)` перед логуванням чи обробкою.
2. Не перехоплюй `CancellationException` вручну.
3. Використовуй `com.intellij.diagnostic.rethrowControlFlowException`, перевіривши фактичні імпорти та доступність API у версії проєкту.
4. Не копіюй приклади механічно, якщо сигнатури або контекст у репозиторії інші; перевір перед застосуванням.
5. Не приховуй помилки порожніми catch-блоками та не підміняй помилку удаваним успіхом.
6. Не заявляй, що код безпечний, без аналізу відповідного потоку даних і контексту.
