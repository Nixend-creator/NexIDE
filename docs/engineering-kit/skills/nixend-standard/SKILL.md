# NIXEND Standard Skill

Перед роботою:
1. Прочитай `AGENTS.md` і `standards/INTELLIJ_PLATFORM_CODING_GUIDELINES_1.0.md`.
2. Визнач, чи це IDE-аналога IntelliJ IDEA; не застосовуй правила Paper/Minecraft.
3. Визнач релевантні розділи стандарту.
4. Якщо вимога задачі суперечить стандарту, повідом про конфлікт і запропонуй мінімальні варіанти.
5. Не перетворюй практичні рекомендації комплекту на нібито дослівні вимоги вихідного документа.
6. Не вигадуй невідомі правила JetBrains, API, версії або результати перевірок.
У звіті вкажи, які розділи стандарту застосовано.
