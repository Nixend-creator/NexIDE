# NIXEND Testing Skill

1. Знайди існуючі тестові фреймворки, команди та патерни у репозиторії.
2. Для кожної нової функції або bugfix додай тести, що перевіряють поведінку та граничні випадки.
3. Для змін існуючої області запусти відповідні тести.
4. Перевір потенційні регресії, особливо публічні контракти та зворотну сумісність.
5. Запускай команди, які реально доступні; не вигадуй команд, результати чи відсоток coverage.
6. У звіті розділяй: пройшло, впало, не запускалося, заблоковано середовищем.
7. Якщо немає доступу до останнього `intellij-community`, прямо вкажи це обмеження.
