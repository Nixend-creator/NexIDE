# NIXEND IDE — Review Checklist

Використовуй цей список перед завершенням задачі або push.

## Задача та diff
- [ ] Зміна відповідає одній логічній задачі.
- [ ] Перевірено весь diff, а не лише останній файл.
- [ ] Немає випадкових rename/move.
- [ ] Немає незавершеного коду або TODO, внесених цією задачею.
- [ ] Немає сторонніх `.idea/*` чи `codeStyleSettings.xml` змін.

## Мова та стиль
- [ ] Нові файли написані Kotlin, якщо немає обґрунтованої потреби змінювати наявний Java-код.
- [ ] Відступи — 2 пробіли, tabs відсутні.
- [ ] Рядки не перевищують 140 символів або відхилення обґрунтоване локальною конвенцією.
- [ ] `else`, `catch`, `finally` починаються з нового рядка.
- [ ] Префікси `my` / `our` застосовані згідно зі стандартом.
- [ ] Нові файли мають Apache 2.0 copyright-заголовок та ім'я контриб'ютора.
- [ ] Дотримано `.editorconfig` і shared code style.

## API та архітектура
- [ ] Використано ідіоматичний Kotlin і null-safety.
- [ ] Immutable-об'єкти та інтерфейси розглянуто там, де доречно.
- [ ] Експериментальні API позначені `@ApiStatus.Experimental`.
- [ ] Не вигадано IntelliJ Platform API або сигнатур.
- [ ] Зворотна сумісність збережена або зміна явно обґрунтована.

## Помилки та документація
- [ ] У `catch (Throwable)` / `catch (Exception)` першим викликається `rethrowControlFlowException`.
- [ ] `CancellationException` не перехоплюється вручну.
- [ ] Нові OpenAPI мають Javadoc/KDoc з призначенням і параметрами.

## Перевірки
- [ ] Додано або оновлено тести для нової функції/багфіксу.
- [ ] Запущено відповідні тести на змінену область.
- [ ] Перевірено регресії.
- [ ] Виконано доступні інспекції; немає попереджень shared Inspection Profile.
- [ ] Виконано Reformat Code (Ctrl+Alt+L), якщо доступно.
- [ ] Збірка/тести виконані проти останньої версії `intellij-community`, якщо це можливо.
- [ ] Невиконані перевірки явно перелічені у фінальному звіті.

## Kotlin build scripts
- [ ] `@JvmField` використано для internal data class fields, де це правило застосовне.
- [ ] `.put()` / `.get()` розглянуто замість `[]`.
- [ ] Явні `HashMap` / `HashSet` / `LinkedHashMap` використані замість `mutableMapOf()` / `mutableSetOf()`.
